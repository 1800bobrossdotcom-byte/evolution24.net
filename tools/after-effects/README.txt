EVOLUTION24 PROPERTIES - THE ANIMATED LOGO, FOR AFTER EFFECTS

What is in this folder
  Evolution24 Logo.jsx   Builds the After Effects project. Run it once, as below.
  Reference/             The website's own animation, recorded at 60 fps, to compare against.
  Vectors/               The logo as SVG, every bar and letter its own named path.

Open it in After Effects
  1. Unzip this folder somewhere After Effects can write to, such as Documents.
  2. In After Effects: File > Scripts > Run Script File..., and choose "Evolution24 Logo.jsx".
  3. It starts a new project, builds the comps, and saves "Evolution24 Logo.aep" in this
     folder. From then on, open the .aep like any project.
     If After Effects says scripts may not write files: Preferences (or Settings) >
     Scripting & Expressions > tick "Allow Scripts to Write Files and Access Network".
     Or just save the project yourself with File > Save As.

The comps, in the folder "Evolution24 Logo"
  Evolution24 Intro 16x9          1920x1080, 60 fps, 3.5 s. The website's intro as it plays on a
                                  laptop: the 15 bars rise one by one from the baseline, the
                                  letters settle in, the line along the bottom fills, and then
                                  the curtain lifts (2.05 to 2.95 s) to show what is underneath.
  Evolution24 Intro 9x16          1080x1920, 2.5 s. The same intro in its phone timing (done by 1.75 s).
  Evolution24 Lockup Build 16x9   1920x1080, 3 s, transparent. The header logo's build: the mark
                                  on the left, the two words stacked to its right.
  Precomps                        Each intro before its curtain. Switch off its "Background" layer
                                  for the logo build on transparency.

How it is built
  - Every bar and letter is a native shape layer, editable like any other.
  - Each logo hangs from a null, "Logo (move and scale me)" or "Lockup (move and scale me)".
    Move or scale the null and the whole animation follows.
  - The keyframes are the website's own: the same delays, durations and easing curves. The
    curves are converted exactly into After Effects' speed and influence, so the graph editor
    shows the website's curve.
  - The curtain is an alpha track matte over the intro. The paper colour that shows once it
    lifts is only the comp's background colour: a render with alpha is transparent there.
  - The letters' blur (16x9 intro only) is a Gaussian Blur with an expression that keeps it in
    proportion when the logo is scaled, as on the website.

Colours
  Ink #151613   Tan #debb92   Cream #e5e6d3 (the "24" and seven of the bars)   Paper #f4f1ea

Exporting
  With transparency (the lockup build, or an intro over footage): Composition > Add to Render
  Queue, Output Module: QuickTime, Apple ProRes 4444, Channels: RGB + Alpha.
  For social or the web: File > Export > Add to Adobe Media Encoder Queue, H.264.

Made from the website's own code (evolution24.net). The script is generated by
tools/after-effects/make.py in the website's repository, from the same logo paths and
animation the site uses, so it can be regenerated if either changes.
