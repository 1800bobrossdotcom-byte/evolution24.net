Dashboard password

Makes the password for evolution24.net/admin/ and the three values Vercel needs. Everything happens in this browser tab; nothing is sent anywhere.

1. The password

Save it in your password manager before going on. It is not kept anywhere, this page included.

2. The values for Vercel

3. Then

  1. Add each value in Vercel → evolution24-net → Settings → Environment Variables, under its own name, for Production.
  2. Close this tab. Making them again gives different values, which is fine: only the ones in Vercel count.
